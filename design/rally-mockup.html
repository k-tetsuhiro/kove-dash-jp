キーボード: ↑ / ↓ = ±0.01 km、R = PART リセット、Space = 一時停止（ハンドルのBluetoothリモコンを想定）

レイアウトの考え方

  • コマ図を読みながら一番見る ODO を左上に最大サイズ（300px）で配置
  • CAP は右上。度数の大きな数字＋コンパステープで向きを直感的に
  • 下段は速度・平均・経過時間・標高・天気。走行中にチラ見する情報
  • ラベルは最小 22px 相当。5インチ TFT でも読める大きさ

データの出どころ

  • ODO / PART / SPEED / AVG / CAP：スマホ GPS（CAP は低速時コンパス補完）
  • ALT：GPS 標高（BLE で送っているのと同じ値）
  • WEATHER：既存の WeatherSource（5分ごと）
  • AVG と TIME は停車中も加算（ラリーの区間平均の考え方）

状態表示

  • ODO 補正時は数字が白く光り、補正量バッジが出る
  • GPS ロスト時は赤点滅、CAP はグレーで最後の値を保持
  • 配色はナビ HUD（KoveColors）と共通
